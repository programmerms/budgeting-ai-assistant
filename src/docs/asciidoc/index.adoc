== Introdução

Esta API permite registrar e consultar transações financeiras (gastos) tanto por endpoints REST convencionais quanto por comandos em linguagem natural (voz e texto) processados com Inteligência Artificial e Tool Calling (Spring AI).

== Convenção Monetária e Categorias

* *Entrada (`amount`)*: informada em *centavos* (`long`), evitando erros de arredondamento de ponto flutuante (ex.: `8000` representa `R$ 80,00`).
* *Saída (`amount` / `total`)*: devolvida em *reais* (`BigDecimal`) com exatamente duas casas decimais (ex.: `80.00`).
* *Categorias disponíveis (`Category`)*: `GROCERIES`, `PHARMA`, `AUTO`, `RESTAURANT`, `SHOPPING`, `TRANSPORT`, `HEALTH`, `LEISURE` e `OTHER`.

== Autenticação

Todos os endpoints de `/transactions` exigem uma sessão autenticada com o papel `ROLE_USER`. Os endpoints de `/api/admin` exigem o papel `ROLE_ADMIN`. Apenas o cadastro e o login são públicos.

O fluxo é: o visitante se cadastra, o cadastro nasce no estado `PENDING`, um administrador aprova, e só então o login funciona. A sessão é mantida por cookie `JSESSIONID`; nos exemplos com `curl`, use `-c cookies.txt` para gravar o cookie e `-b cookies.txt` para reenviá-lo.

== Comandos de IA (Voz e Texto)

Além dos endpoints REST acima, a API oferece dois canais conversacionais acionados pelo assistente financeiro:

* `POST /transactions/ai` (`multipart/form-data`, campo `file`): recebe um arquivo de áudio, transcreve com Whisper (`whisper-1`), executa Tool Calling com `gpt-4o-mini` e devolve um arquivo `audio/mp3` (`gpt-4o-mini-tts`).
* `POST /transactions/ai/text` (`application/json`, `{"message": "..."}`): recebe o comando em texto e devolve `{"message": "..."}` com a resposta textual da IA após acionar as ferramentas necessárias.

== Códigos de Status

|===
| Código | Descrição

| 200 OK       | Consulta, login ou comando executado com sucesso
| 201 Created  | Transação ou cadastro criado com sucesso
| 204 No Content | Sessão encerrada com sucesso
| 400 Bad Request | Erro de validação nos campos, parâmetros ou arquivo de áudio vazio
| 401 Unauthorized | Falha de autenticação ou requisição sem sessão válida
| 403 Forbidden | Sessão válida, mas sem o papel exigido pelo endpoint
| 404 Not Found | Cadastro inexistente
| 409 Conflict | Nome de usuário já em uso ou cadastro já decidido
| 500 Internal Server Error | Falha inesperada ou indisponibilidade do provedor externo de IA
|===
